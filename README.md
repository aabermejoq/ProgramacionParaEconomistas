# Introducción a la Programación para Economistas

Diez clases para aprender a trabajar con datos usando R y Python. No se requiere experiencia previa — sí ganas de dejar de hacer todo en Excel.

El curso no es exhaustivo, pero sí suficiente para empezar a ser autónomo.

## Clases

| # | Tema | Lenguaje |
|---|------|----------|
| 1 | Git, Markdown e introducción a R | R |
| 2 | Manipulación de datos con tidyverse | R |
| 3 | Econometría en R | R |
| 4 | Visualización de datos | R |
| 5 | Web scraping | R |
| 6 | Introducción a Python, For-loops y list comprehensions  | Python |
| 7 y 8 | Limpieza de datos con pandas y uso de APIs | Python |
| 9 y 10 | Machine Learning aplicado a economía | Python |

## Curso complementario: Programar con criterio en la era de la IA

Cinco sesiones de 90 minutos en R Markdown, para personas que nunca han programado, sobre por qué sigue siendo necesario aprender a programar cuando una IA puede escribir el código: leerlo, detectar sus decisiones, comprobar resultados y responsabilizarse de lo que se presenta. El caso de trabajo son los datos del NFL Scouting Combine (2009-2019). Los cinco R Markdown para estudiantes, con todas las instrucciones, y los datos están en [`Curso_Programar_con_IA_NFL/estudiantes/`](Curso_Programar_con_IA_NFL/estudiantes/).
